# Magic Carpet Knight – فارس البساط السحري

لعبة Godot 4.7.2 ثلاثية الأبعاد من نوع **Endless Runner**. يقود اللاعب فارسًا مدرعًا فوق بساط سحري في عالم خيالي ملوّن، ويتفادى الصخور والبوابات ويجمع البلورات مع ازدياد السرعة.

## ما يعمل في النسخة الأولى

- حركة تلقائية للأمام مع ثلاثة مسارات وثلاثة ارتفاعات.
- تحكم بالأسهم أو WASD على سطح المكتب، وتحكم بالسحب يمينًا ويسارًا وأعلى وأسفل على الهاتف.
- توليد مستمر للعقبات والجواهر مع إعادة تدويرها أثناء الرحلة.
- صخور وبوابات متوهجة وبلورات قابلة للجمع مع تأثير ضوئي بسيط.
- فارس وبساط مركبان من أشكال Godot الإجرائية المصقولة بالألوان والخامات والإضاءة والظلال؛ لا تُقدَّم كمجسمات احترافية جاهزة.
- نقاط تزداد مع المسافة والجواهر، حفظ أفضل نتيجة محليًا، وشاشات عنوان وإيقاف مؤقت وخسارة وإعادة لعب.
- واجهة اللعبة باللغة العربية افتراضيًا.

## التشغيل المحلي غير المتعلق بـ Android

يتطلب المشروع Godot 4.7.2. لتشغيل الفحص المنطقي:

```bash
npm run check
```

ولتشغيل اللعبة من Godot:

```bash
godot --path . --editor
```

لا يثبت هذا المشروع Android SDK أو NDK أو JDK على الهاتف. تصدير APK مقصود له أن يتم في GitHub Actions فقط.

## التصدير السحابي

ملف `.github/workflows/android-apk.yml` يجهز Godot Export Templates وAndroid SDK/JDK داخل بيئة GitHub Actions، ثم يصدر `build/magic-carpet-knight.apk` بمعمارية `arm64-v8a` وباسم الحزمة `com.magiccarpetknight.game`. يرفع الملف كـ Artifact، وينشئ GitHub Release تلقائيًا عند تشغيل Workflow من خلال Tag.

## هيكل مختصر

- `project.godot`: هوية اللعبة والإدخال والإعدادات.
- `scenes/main.tscn`: المشهد الرئيسي.
- `scripts/magic_carpet_game.gd`: العالم الإجرائي، الحلقة، التحكم، النقاط، الواجهات والحفظ المحلي.
- `test/magic_carpet_check.gd`: فحص bounded للتحميل، الحركة، النقاط، الإيقاف والاستئناف.
- `export_presets.cfg`: Web وAndroid arm64 presets.
- `game-sharing.json`: بيانات المشاركة والأيقونة الخاصة باللعبة.
- `.github/workflows/android-apk.yml`: بناء APK سحابي ورفع Artifact/Release.

## حدود التحقق

تم تجهيز فحص Godot آلي للمنطق الأساسي. لم يُدَّعَ اختبار السحب الفعلي على هاتف حقيقي؛ اختبار اللمس الفعلي يحتاج جهاز Android أو Emulator متاحًا للمستخدم.
